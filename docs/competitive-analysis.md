# 竞品分析：AI 赛博土木（抖音 72268320355）与复刻路线

> 参考：抖音视频 7631479403532626313「土木 AI 邪修之造价 Agent」（35.6s，2160×3840）
> 本文档为学习分析用途的功能拆解与复刻规划。

## 一、他的形态（三帧全解）

### 1. 智能开项（对话式创建项目）
- 中文对话：项目名/建筑面积/层数/结构类型 → 自动生成 **30 项工程量清单**
- 分部工程：混凝土及钢筋混凝土(8)/措施项目(5)/土石方(3)/装饰装修(7)/其他(7)
- **关键工程量指标**（造价师核心知识）：混凝土总量 1320m³（单方 0.44m³/m²）、钢筋 138t（46kg/m²）、模板 9450m²（3.15m²/m²）、砌体 405m³（0.135m³/m²）
- 下一步建议驱动：智能组价 / 查看清单详情 / 调整清单

### 2. 智能组价
- 30 项清单绑定定额计综合单价 → 明细表（编码/名称/单位/工程量/单价/合价）
- **费用结构分析**：措施 30.1% / 装饰 32.5% / 主体 16.8% / 土方 9.0%
- **项目总造价 ¥109,824**；JSON 报告可导出 Excel/PDF
- 页面可见 `delegate_adversarial_review` / `delegate_insight` —— **子代理委派架构**（Claude Code 式）

### 3. 完整 Web 面板（造价 SaaS 级 UI）
- 左侧导航：仪表盘 / 清单树 / **定额绑定** / **计算溯源** / 校验 / **快照对比** / 计价报告 / 智能开项 / 设置
- 分部工程树 11 类 + 清单表格 + 「AI 智能开项」「Excel 导出」顶栏

## 三、复刻路线（按价值排序）

### R1 真模型工程量指标（`aec_quantity`）
从 Revit 真模型出工程量：墙/板/柱/梁体积与长度 → 汇总混凝土/模板/砌体量 → **单方含量指标**（÷建筑面积）。
比他的"假设指标"强一代：数字来自真实构件参数，可溯源到每个 element_id。
实现：桥 `query_elements`（读 Wall.Volume / Floor.Area / 结构柱体积参数）→ 汇总 → 指标表。

### R2 设计→造价全链路（降维打击）
真模型工程量 → 清单映射（GB50500 编码规则）→ 定额绑定（知识库/JSON 定额表）→ 综合单价 → 费用结构分析 → 总造价报告（Excel/PDF）。
他的天花板是"假设数据"，我们打通"真模型→造价"。

### R3 面板深化
清单树 + 工程量指标卡 + 费用结构图 + 计算溯源（每项工程量可点开看构件明细）。

### R4 多版本 Revit（详见 multi-version.md）
2020-2024 桥官方就绪（编译矩阵）；2025-2026/2027 需 .NET 8 适配器（桥作者未做）；
aec-mcp 客户端天然版本无关（按年份队列+端口路由）。
